## Previous Projects

### FYP Governance & Collaboration Platform

**React · Node.js · Express.js · MongoDB · Socket.io · WebRTC · JWT**

A full-stack academic governance and collaboration platform for Students, Teachers, and Administrators.

- Designed a **3-role RBAC system** around a 6-state proposal workflow with concurrency-safe supervisor allocation using atomic MongoDB updates and partial unique indexes.
- Implemented **dual-JWT authentication** with refresh-token rotation and reuse detection, storing refresh tokens as SHA-256 hashes in httpOnly cookies.
- Built real-time messaging with read receipts and reactions, along with **1-to-1 WebRTC video calling** using ICE/SDP signaling.
- Added layered API security with Helmet, MongoSanitize, CORS allowlists, rate limiting, JWT guards, RBAC guards, and centralized error handling.

**Live:** https://project-management-system-c3ow.vercel.app
